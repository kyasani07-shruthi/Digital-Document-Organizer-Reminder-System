# DocVault — Document Organizer & Reminders

This is a **standalone front-end demo inspired by the visible landing page** at https://screenshot-align-friend.lovable.app/. It is not an export of the original Lovable source code.

## Files
- `index.html` — landing page, sign-in demo, dashboard structure
- `style.css` — responsive styling
- `script.js` — demo login, add/edit/delete/search/filter documents, expiry status calculations
- `README.md` — setup notes

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Click **Get started**, enter a display name, and add sample documents.

## Important limitations
- This is a browser-only prototype; document details are saved in this browser's `localStorage`.
- It does not include real user authentication, a server/database, email/SMS reminders, or secure file uploads.
- Do not enter sensitive real-world document data.
- The original deployed website's full source cannot be recovered from its public URL alone. To get the exact original project, open the project in Lovable and use its code export/GitHub integration, then share the exported project ZIP or repository.
